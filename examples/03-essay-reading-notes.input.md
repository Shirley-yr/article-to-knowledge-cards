# 关于读书笔记的一点感想

我读了很多年书，也记了很多年笔记，最近才想明白一个我一直搞错的事情。

以前我总觉得笔记的价值在于"保存"。读到好东西，赶紧抄下来，怕它跑了。于是我的笔记越攒越多，五本笔记本，几千条摘录，可我一年也翻不了几次。那些抄下来的句子看着眼熟，用的时候却一句也想不起来。

后来我意识到，记笔记的目的根本不是保存。书里的东西本来就在书里，跑不掉，我不需要再存一遍。我真正需要的是让它变成我的。而变成我的唯一办法，是我用自己的话把它重新说一遍。哪怕说得没原文漂亮、没原文准确，那个磕磕绊绊的重述过程本身才是内化。

这个道理我后来又绕回来想过好几次。保存和内化是两件事。保存靠复制，内化靠重述。我过去所有的笔记动作几乎都落在前者，所以我攒了一堆看起来很像样的东西，脑子里却空空如也。

还有第三件事：回看。重述过一次不等于永远记住，隔一段时间把它拿出来，合上原文，自己讲一遍，才看得出哪里是真空的。我现在每周挑一天做这件事，讲不顺的地方就是我没懂的地方。这比再读一遍原文管用得多。

所以我现在记笔记很简单：一句话，用自己的话写；不确定的地方标记出来；一周后回看。至于抄原文这件事，我基本不做了。

有人可能会说，摘录原文也是一种积累。也许吧，但对我来说，那更像收藏邮票，而不是学习。我需要的不是更多的笔记，是更少的、但真的属于我的笔记。
