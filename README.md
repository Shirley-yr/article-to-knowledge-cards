# make-knowledge-cards

一个开源的 Agent Skill：把一篇文章提炼成 **5–8 张知识卡片**，一张卡只讲一个知识点。

## 1. 这个项目解决什么问题

读了一篇长文，合上就忘。做摘要只是把文章压短，仍然是一段连续文字，不方便复习，也看不出哪些是真正该记住的。

这个 Skill 做的是**筛选**而不是压缩：从原文里挑出真正值得记住的知识，每张卡只放一个知识点，配上解释和一个例子或自测题，产出可以直接拿来复习、自测或放进你自己的笔记/记忆工具。

它同时解决三个具体的常见问题：

- **卡片注水**：凑不够 5 张就硬拆、硬编——这里明确禁止，信息不足就出 3 张并说明原因。
- **一卡多义**：一张卡塞进两个知识点——这里用"一句话合并测试"来判断该拆还是该合。
- **凭空补充**：原文没写的例子、数据、结论被 AI 脑补进去——这里把"只用原文信息"写成硬性禁令。

## 2. 主要功能

| 功能 | 说明 |
| --- | --- |
| 文章转卡片 | 粘贴的文本或本地 `.md` / `.txt` 文件 → 5–8 张知识卡片 |
| 四要素卡片 | 每张卡固定：标题 · 核心知识 · 简明解释 · 例子或自测 |
| 重要度筛选 | 按"忘掉它损失多大"排序，只保留承重信息，丢掉铺垫、修辞、逸事 |
| 去重合并 | 原文反复重申的同一论点合并成一张；"一句话合并测试"判定是否重复 |
| 不编造 | 不补原文没有的例子、数据、结论、术语或后果；原文的条件限定原样保留 |
| 不足不凑数 | 去重后不足 5 个知识点就出更少的卡，并在结尾用一行说明原因 |
| 自测题兜底 | 原文没有例子时，出一道"原文能自己回答"的自测题，且不给提示、不泄答案 |
| 边界明确 | 不支持的输入直接说不支持并给替代方案，不硬凑一个结果 |

**能力边界（明确不做）**：网页抓取 / URL、PDF · DOCX · EPUB · 图片 · 扫描件、Anki 牌组导出（`.apkg`）、图形界面或渲染成图。

## 3. 安装方法

零依赖：整个 Skill 只有 `SKILL.md` 和 `agents/openai.yaml` 两个文件，没有脚本、不需要装包。

把 `skills/make-knowledge-cards/` 整个目录复制到你的 skills 目录即可：

| 范围 | 路径 | 适用 |
| --- | --- | --- |
| 用户级 | `~/.workbuddy/skills/`（WorkBuddy）<br>`~/.codebuddy/skills/`（CodeBuddy 生态） | 所有项目通用 |
| 项目级 | `.workbuddy/skills/` 或 `.codebuddy/skills/` | 随仓库共享给协作者 |

安装后目录形如 `~/.workbuddy/skills/make-knowledge-cards/SKILL.md`。

仓库结构：

```
.
├── README.md
├── LICENSE
├── .gitignore             # 忽略 .workbuddy/、output/ 与临时文件
├── skills/make-knowledge-cards/
│   ├── SKILL.md            # Skill 本体：工作流、卡片结构、质量规则、自检清单
│   └── agents/openai.yaml  # UI 元数据（display_name / short_description / default_prompt）
├── examples/               # 三种文体的输入与输出样例
└── output/                 # 本地实战产出，已被 .gitignore 忽略
```

## 4. 使用方法

安装后直接说人话，不需要记命令：

```
把这段做成知识卡片
把 ~/notes/http-cache.md 转成知识卡片
给这篇文章出 6 张学习卡片
```

两种输入方式：

1. **直接粘贴**：把文章贴在对话里，再说一句上面的话。
2. **本地文件**：给出 `.md` / `.markdown` / `.txt` 的路径。

输出是 Markdown，结尾附一行总结（如 `共 6 张卡片，来源：《睡眠与记忆巩固》。`）；卡片少于 5 张时会再补一行说明原因。需要 JSON、表格或别的语言，直接提要求即可。

## 5. 输入输出示例

### 输入

> 慢波睡眠期间，海马体会把白天形成的记忆以高频振荡的形式"重放"一遍，并把它们逐步转移到新皮层长期保存。睡眠纺锤波越密集的人，第二天回忆成绩通常越好。

### 输出

```markdown
## 卡片 1：记忆的系统巩固

**核心知识**：慢波睡眠期海马体"重放"白天记忆并转移到新皮层，是记忆转为长期保存的关键环节。

**简明解释**：新记忆先快速写入海马体，容量有限；慢波睡眠期间海马体以高频振荡重放这些痕迹，
新皮层借机把内容固化下来。这解释了为什么睡够比事后复习更能稳住新知识。

**例子 / 自测**：原文提到睡眠纺锤波越密集，第二天回忆成绩通常越好——若睡眠被打断，最先受损的
应该是刚学的新内容，为什么？
```

更完整的真实案例见 `examples/`，三种文体各一组输入与输出：

| 样例 | 文体 | 卡片数 | 验证点 |
| --- | --- | --- | --- |
| `01-science-sleep-memory` | 科普说明 | 7 | 机制与量级成卡、学界争议保留不确定性 |
| `02-tech-http-cache` | 技术教程 | 8 | 并列列表的拆分与合并、术语入标题 |
| `03-essay-reading-notes` | 个人随笔 | 3 | 去重、信息不足时**不凑数**并给出说明 |

实战案例：`output/网络空间安全-知识卡片.md`（8 张，演示 OCR 损坏文本只取可确读内容）。

## 测试与验证

结构校验：

```bash
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
# Skill is valid!
```

改完 `SKILL.md` 建议：重跑上面的校验，再用不同文体的文章各测一轮，重点确认数量控制、去重、"不凑数"这三条最容易跑偏的规则。
